# okaziya.github.io

Root site for GitHub Pages at https://okaziya.github.io/.

## What's here

- **`index.html`** — Redirects visitors to the CV site at [/cv/](https://okaziya.github.io/cv/)
- **`robots.txt`** — Allows all crawlers and references the sitemap
- **`sitemap.xml`** — Lists all pages under okaziya.github.io for search engine discovery (submitted via [Google Search Console](https://search.google.com/search-console))

## Related repos

- [okaziya/cv](https://github.com/okaziya/cv) — The CV site, deployed to `/cv/`
